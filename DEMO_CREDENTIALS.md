## Quick demo journey

### Employee
1. Sign in as **employee** → Goal Sheet → create 3–4 goals, total weightage = 100%
2. Submit for approval
3. After manager approves → Quarterly Check-in → log Q1 actuals

### Manager
1. Sign in as **manager** → Approvals → review inline, edit target/weightage → Approve All
2. Check-ins → add a comment for each employee's Q1 entry

### Admin
1. Sign in as **admin** → Cycles → activate Q1 window
2. Shared Goals → push a departmental KPI to multiple employees
3. Escalations → Run Escalation Check
4. Analytics → view QoQ charts and manager effectiveness
5. Achievement Report → Export Excel / CSV
6. Audit Trail → view all locked-goal changes
7. Manage Goals → unlock a goal for employee correction

## Role switcher
If your account has all 3 roles assigned, use the **Demo** pill in the top-right header to switch between roles without logging out.
